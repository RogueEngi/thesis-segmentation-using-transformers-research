# Notebook Index

This folder groups the Colab notebooks used for the first phase of the thesis work.

## Setup

- `setup/phase_one_colab_setup.ipynb` - dependency installation and Colab cache setup.

## Training

- `train/setr_train.ipynb` - dataset-selectable SETR workflow.
- `train/segmenter_train.ipynb` - dataset-selectable Segmenter workflow.
- `train/segformer_train.ipynb` - dataset-selectable SegFormer workflow.
- `train/mask2former_train.ipynb` - dataset-selectable Mask2Former workflow.

## Evaluation

- `eval/setr_eval.ipynb`
- `eval/segmenter_eval.ipynb`
- `eval/segformer_eval.ipynb`
- `eval/mask2former_eval.ipynb`
- `eval/generic_eval.ipynb` - archived evaluation scratch notebook.

## Archive

- `archive/old_scratch.ipynb` - scratch notebook kept only for traceability.
