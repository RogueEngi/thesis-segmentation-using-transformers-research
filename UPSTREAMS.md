# Upstream Provenance

This repository is a thesis-oriented fork built from external open-source projects.

## Base Segmentation Framework

- [`facebookresearch/mask2former`](https://github.com/facebookresearch/mask2former)
- Used as the starting point for the phase-two implementation.

## Boundary-Loss Reference

- [`LIVIAETS/boundary-loss`](https://github.com/LIVIAETS/boundary-loss)
- Used as the reference for the boundary-loss formulation and signed-distance-map logic.

## Colab Baselines

- Phase-one notebooks and configs were created by adapting OpenMMLab/MMEngine/MMSegmentation workflows for the thesis experiments.
